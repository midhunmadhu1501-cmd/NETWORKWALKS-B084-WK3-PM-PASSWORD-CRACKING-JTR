# 🔐 Password Cracking Using John the Ripper & Networkwalks Tools

## 📌 Project Overview

This project is part of **Week 3 of my Cybersecurity Internship**. It focuses on understanding password recovery techniques using two different approaches: John the Ripper (JTR) and Networkwalks Password Cracking Tools.

The practical exercises demonstrate how password hashes can be extracted from password-protected PDF files and tested against dictionary wordlists to recover weak passwords.

The project provides hands-on experience with password hashing, hash extraction, dictionary attacks, and basic password security assessment.

## 🎯 Objectives

- Understand password hashing and hash extraction.
- Learn how password-cracking techniques work.
- Perform dictionary-based password attacks.
- Explore industry-used password auditing tools.
- Understand the importance of strong password practices.

## 📂 Project Modules

### Module 1: Password Cracking with John the Ripper (JTR)

**Objective:** Recover the password of a protected PDF using John the Ripper and Johnny GUI.

**Workflow:**
1. Installed and configured John the Ripper and Johnny GUI.
2. Obtained the encrypted PDF file.
3. Extracted the PDF password hash using an online PDF hash extractor.
4. Saved the extracted hash in a text file.
5. Imported the hash file into Johnny.
6. Started the dictionary-based password attack.
7. Recovered the password successfully.
8. Verified the recovered password by opening the protected PDF.

### Module 2: Password Cracking with Networkwalks Tools

**Objective:** Recover a protected PDF password using Networkwalks online tools.

**Workflow:**
1. Obtained the encrypted PDF file.
2. Uploaded the PDF to the Networkwalks Hash Calculator.
3. Extracted and copied the complete PDF hash.
4. Opened the Networkwalks Password Cracker.
5. Pasted the extracted hash into the tool.
6. Selected the built-in dictionary wordlist.
7. Initiated the password-cracking process.
8. Successfully recovered the password.
9. Verified the result by opening the PDF.

## 🧠 Key Concepts Learned

- **Password Hashing:** Understanding how passwords are represented as hash values.
- **Hash Extraction:** Retrieving password-related hash information from protected PDF files.
- **Dictionary Attack:** Testing potential passwords from a predefined wordlist.
- **Password Auditing:** Evaluating password strength through controlled security testing.
- **Password Security:** Understanding why weak and commonly used passwords are vulnerable.
